SkyPop 1.1.0 — The Shattered Sky
QuietByte · hello@quietbytehq.uk

Extract the entire ZIP, then double-click SkyPop.exe.
Requires 64-bit Windows 10/11 and OpenGL 3.3-compatible graphics.
Godot is not required. F11 toggles fullscreen; Escape opens Resume / Quit.

Move: arrows / A-D. Fire: Space. Keyboard, mouse and gamepad controls
are described in README.md and can be configured from Settings.
Enter/Space/A/click advances the story; Escape/B skips it.
Clear all ten worlds to see the victory ending.

Optional global scores: https://skypop.quietbytehq.uk
Name entry explains public posting. F2 / gamepad X toggles remembered
local-only scoring. Only name, score, mode and game version are sent.
Scores are self-reported, not verified; offline submissions are dropped.
