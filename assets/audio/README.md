# Optional audio

The downloadable game bundles its licensed soundtrack and effects. Raw audio files are intentionally excluded from this source repository: ElevenLabs Sound Effects terms restrict distribution as isolated audio files. Audio is not licensed under Apache-2.0.

The source build works silently. To add audio you may lawfully redistribute, place MP3, OGG or WAV files here (MP3 takes precedence), using these names:

fire, heal, hit, jump, pickup, pop, shield, special, stage, music, title_music, happy_music, sad_music, voice_ouch, voice_fall, voice_alright.

`music` and `title_music` loop. Happy/sad music and voices play once.
